# Restorations gallery: photo credits

Example photos of classic motorcycles from Wikimedia Commons, shown in MotoGarage's restorations gallery until the workshop's own photos replace them. They are not MotoGarage's work and the site credits each one.

Each file was resized to 1600 px wide and re-encoded as JPEG; nothing else was changed. Metadata (author, license, source) comes from the Commons API (`prop=imageinfo&iiprop=url|extmetadata`), with the author's HTML reduced to plain text.
