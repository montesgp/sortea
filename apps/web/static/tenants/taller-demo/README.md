# Taller Demo images

Images of Taller Demo, the fictional organization that the seed creates for local development and tests (`packages/db/src/packs/taller-demo.ts`).

- `logo.png`, `logo-180.png`, `favicon.png`, `taller.jpg` (with `taller-480.webp` and `taller-689.webp`), `manual-tecnico.webp`, `checklist-viaje.webp`, `calcomania.jpg`, `remera.jpg` and `premios/kit.jpg` are placeholders generated for this repository from plain shapes: no photo, font or third-party material.
- `premios/moto.jpg`, `premios/efectivo.jpg` and `restauraciones/*.jpg` are openly licensed photos from Wikimedia Commons, credited in the `CREDITS.md` next to them.

The file names follow the site's conventions: the header uses `logo-180.png` and the browser tab `favicon.png` next to the brand's `logo.png`, and the garage hero loads `<image>-480.webp` and `<image>-689.webp` next to its `.jpg`.
